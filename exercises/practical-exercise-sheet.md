# Practical Exercise Sheet
**Workshop:** Getting Started with Git and GitHub: From Zero to Your First Repository  
**Organisers:** KYUCSA & Concept Crashers — Kyambogo University  

---

## Exercise 1: Create Your First Repository (Activity 5)
**Goal:** Create a repository on GitHub, edit the README file, and record your first commit.

1. Open your browser and sign in to your GitHub account at [github.com](https://github.com).
2. Click the **+** icon in the top-right corner and select **New repository**.
3. Name your repository `my-first-project`.
4. Add a short description (for example: *My first GitHub repository*).
5. Select **Public**.
6. Check the box **Add a README file**.
7. Click **Create repository**.
8. Open `README.md` by clicking on it, then click the **pencil icon (Edit this file)**.
9. Add your name, your course at Kyambogo University, and one technology skill you want to learn.
10. Click **Commit changes...**, write a short commit message (for example: `Add my introduction to README`), and click **Commit changes**.
11. Return to the main repository page and confirm your changes appear on screen.

## Exercise 2: Pair Collaboration with Branches and Pull Requests (Activity 9)
**Goal:** Work with a partner to propose a change on a separate branch, review it, and merge it.

### Part A: Contributor (Making the Change)
1. Open the shared practice repository (`demo-project`) provided by the facilitator.
2. Click the branch dropdown (currently showing **main**).
3. Type a new branch name such as `add-your-name` and select **Create branch**.
4. Open `index.html` (or `README.md`), click the **pencil icon**, and add your name to the attendees list.
5. Scroll down, select **Commit changes...**, make sure you are committing to your **new branch** (not `main`), and click **Commit changes**.
6. Click the **Compare & pull request** banner at the top of the repository.
7. Write a clear title and short description explaining what you changed, then click **Create pull request**.

### Part B: Reviewer (Reviewing Your Partner's Pull Request)
1. Open your partner's Pull Request from the **Pull requests** tab.
2. Click the **Files changed** tab to inspect what lines were added or edited.
3. Leave a polite, helpful review comment on their Pull Request.
4. Click **Merge pull request** and then **Confirm merge**.

*Note: Switch roles if time permits so both partners get to create and review a Pull Request.*

---

## Exercise 3: Final Practical Challenge (Activity 10)
**Goal:** Apply what you have learned independently to start a real project repository.

1. Create a new repository on GitHub for a project idea you want to build (for example: `campus-study-planner` or `personal-portfolio`).
2. Initialise it with a `README.md` file.
3. Edit `README.md` so it clearly includes:
   - **Project Name**
   - **Purpose:** What problem the project solves or what it is intended to do.
   - **Goals:** What you hope to learn or build with this project.
4. Commit your changes with a descriptive commit message.
5. **Bonus step:** Create a new branch, add a `TODO.md` or update your project goals, and open a Pull Request.
6. Share your repository link with the facilitator or your partner for quick feedback.
