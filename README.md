# Getting Started with Git and GitHub: From Zero to Your First Repository

A 3-hour, beginner-friendly practical workshop designed for students at Kyambogo University (organized with KYUCSA and Concept Crashers).

## Workshop Overview
- **Target Audience:** University students with little or no prior experience with Git and GitHub.
- **Duration:** 3 Hours (180 minutes)
- **Format:** In-person hands-on lab, live demonstrations, and pair collaboration.

## Repository Structure
- `presentation/workshop-slides.pdf` – Slide deck covering version control basics, Git vs. GitHub, commits, branches, and pull requests.
- `demo-project/` – Simple HTML/CSS starter project used during live demonstrations and pair exercises.
- `resources/git-commands-reference.pdf` – One-page command cheat sheet for attendees to keep.
- `exercises/practical-exercise-sheet.pdf` – Step-by-step instructions for the hands-on activities and final challenge.
- `facilitator/facilitator-guide.pdf` – Run-of-show, timing, setup checklist, and troubleshooting guide for organizers.
- `feedback/participant-feedback-form.md` – Post-workshop feedback survey questions.

## Prerequisites for Attendees
1. A laptop (or paired workstation) with a web browser.
2. A free [GitHub account](https://github.com/signup).
3. [Git](https://git-scm.com/downloads) and a code editor (such as [VS Code](https://code.visualstudio.com/)) installed.
