# Kyambogo Student Developer Starter Project

Welcome to the practice repository for the **Getting Started with Git and GitHub** workshop!

## How to Use This Repo
1. Fork or clone this repository to your machine.
2. Create a new branch (e.g., `git checkout -b add-my-name`).
3. Add your name and track to `index.html` or `contributors.md`.
4. Commit your change, push your branch, and open a Pull Request!
